# املاک اشکان — بازطراحی وب‌سایت املاک

نسخه بازطراحی‌شده پروژه قدیمی HTML/CSS با تمرکز بر ظاهر مدرن، تجربه کاربری، سرعت، دسترس‌پذیری و SEO.

## امکانات
- طراحی کاملاً Responsive و RTL
- جست‌وجو و فیلتر ملک بر اساس معامله، موقعیت، نوع و قیمت
- علاقه‌مندی‌ها با localStorage
- کارت‌های مدرن املاک و جست‌وجو بر اساس محله
- فرم ثبت ملک و خبرنامه (دموی فرانت‌اند)
- چت‌بات راهنمای هوشمند سمت کاربر (Rule-based، بدون نیاز به API)
- SEO: meta description، Open Graph، canonical، semantic HTML و Schema.org
- Lazy loading تصاویر، فونت با font-display و رعایت prefers-reduced-motion
- منوی موبایل، Skip Link و بهبودهای پایه دسترس‌پذیری
- بدون وابستگی به jQuery/Bootstrap در نسخه جدید

## اجرا
فایل `index.html` را مستقیماً باز کنید یا پروژه را با یک static server اجرا کنید.

## اتصال چت‌بات واقعی
چت‌بات فعلی بدون بک‌اند کار می‌کند. برای پاسخ‌های مولد واقعی، endpoint امن سمت سرور بسازید و کلید API را هرگز در JavaScript فرانت‌اند قرار ندهید.

## صفحات و امکانات افزوده‌شده در نسخه توسعه‌یافته
- صفحه فهرست املاک
- درباره ما
- خدمات
- مشاوران
- تماس و فرم درخواست مشاوره
- سوالات متداول
- مجله و صفحه مقاله
- محاسبه‌گر تقریبی اقساط
- حریم خصوصی و شرایط استفاده
- صفحه 404
- sitemap.xml، robots.txt و Web App Manifest
- ساختار Responsive و RTL مشترک برای صفحات داخلی

> دامنه example.com در sitemap/robots فقط placeholder است و پیش از انتشار باید با دامنه واقعی جایگزین شود.

## امکانات نسخه Pro
- صفحه جزئیات اختصاصی ملک و گالری تصاویر
- تور مجازی 360 درجه نمایشی با Drag
- جست‌وجوی پیشرفته چندفیلتره و مرتب‌سازی
- مقایسه تا 4 ملک با localStorage
- نقشه تعاملی نمایشی املاک
- ورود/ثبت‌نام نمایشی و داشبورد کاربر
- ثبت و مدیریت آگهی و ذخیره محلی
- اعلان‌ها و تاریخچه بازدیدها
- علاقه‌مندی‌ها، محاسبه‌گر مالی، مجله، FAQ و صفحات حقوقی

نکته: احراز هویت، آپلود واقعی، نقشه واقعی، اعلان Push و داده‌های آگهی برای محیط Production به Backend/API نیاز دارند. کلیدهای سرویس‌ها نباید در JavaScript فرانت‌اند قرار گیرند.
